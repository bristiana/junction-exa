# Exa: The Internet Butler / Your Personal Assistant

This is the full brief from hackjunction.app (Junction 2026, event 45).

## The challenge
Build an agent that takes tedious tasks in people's lives off their hands. It should:
- find what matters across the web;
- work out what needs to happen;
- get the task as close to done as it can, leaving the final approval to the user if needed.

**Demo it on a real case.**

**Areas of interest:** general tasks. The brief's examples are planning special occasions, daily errands, rent (is an increase legal?), missed benefits, business information and travel disruption.

## Judging (20% each)
| Criterion | What judges look for |
|---|---|
| Use of Exa | Information retrieved with Exa that could not have come from a model's training data alone |
| Usefulness | How useful it is to a specific group of real people |
| Clarity | How clearly it shows its sources |
| Originality | How original the idea is |
| Working implementation | Whether the demo works on live queries, including ones the judges try themselves |

## What Exa provides
- **Credits:** $50 in Exa credits per participant. Redeem the code `EXA50JUNCTION` at dashboard.exa.ai/billing.
- **Search API:** fast, balanced and deep research modes.
  - Filters: date, domain, category (news, research papers, companies, people, personal websites).
  - Results can come back as structured JSON.
- **Contents API:**
  - full page text, highlights and summaries;
  - crawling a site's subpages;
  - **past versions of web pages**.
- **Other tools:**
  - **Websets:** verified lists of people, companies and opportunities.
  - **Monitors:** recurring searches.
  - A hosted MCP server.
  - Python and JavaScript SDKs.
- **Help and examples:**
  - working examples at demos.exa.ai;
  - Exa engineers on site;
  - a Discord channel.
